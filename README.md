# SauceDemo Automation Testing Framework

A Selenium WebDriver automation project built with **Java, TestNG, Maven, and the Page Object Model (POM)** to test key user journeys on the SauceDemo demo e-commerce website.

## Project Overview

This project automates essential shopping workflows on [SauceDemo](https://www.saucedemo.com/), including login, adding a product to the cart, and completing the checkout process. The framework separates page locators and actions from test logic to improve readability and maintainability.

## Tech Stack

- **Language:** Java
- **UI Automation:** Selenium WebDriver
- **Test Framework:** TestNG
- **Build and Dependency Management:** Maven
- **Design Pattern:** Page Object Model (POM)
- **Browser:** Google Chrome

## Automated Scenarios

- Verify login functionality.
- Add the Sauce Labs Backpack to the shopping cart.
- Verify that the selected product appears in the cart.
- Complete the checkout form.
- Verify the order confirmation message.
- Capture screenshots at selected points in the test flow, where configured.

> Note: The exact scenarios executed depend on the test classes currently present in the repository.

## Prerequisites

Install the following:

1. **JDK 17 or later** (the project should compile against the Java version configured in `pom.xml`).
2. **Apache Maven 3.9 or later**.
3. **Google Chrome**.
4. **Git**.
5. **Visual Studio Code** or another Java IDE.

Check your installations:

```bash
java -version
mvn -version
git --version
```

## Run the Tests

1. Clone the repository or open the project folder.
2. Open a terminal in the folder containing `pom.xml`.
3. Run the test suite:

```bash
mvn clean test
```

To compile the project without running tests:

```bash
mvn clean compile
```

Test reports are usually generated under:

```text
target/surefire-reports/
```

## Framework Design

- **BaseTest:** Shared WebDriver setup, teardown, and reusable test utilities such as screenshot capture.
- **Page classes:** Keep web element locators and page actions separate from test cases.
- **Test classes:** Execute user workflows and validate expected results with assertions.
- **Maven:** Manages project dependencies and provides standard build/test commands.
- **TestNG:** Organizes and executes automated test cases.

## Screenshots and Reports

If screenshot capture is enabled, screenshots are saved in the configured screenshot directory. TestNG/Surefire reports are available under `target/surefire-reports/` after execution.

Generated files such as `target/` and temporary IDE files should generally not be committed. Keep only useful project source files and intentionally maintained documentation in Git.
